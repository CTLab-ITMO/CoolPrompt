# Playbook examples for `hyper_light_playbook`

These playbooks were generated by `gpt-4o-mini` from the benchmark start prompts.
They are task-level strategy examples, not playbooks generated from individual
dataset records.

## SQuAD v2 — contextual question answering

### Task summary

Provide an answer based on a given context in response to a question.

### Strategies

#### Contextual Analysis

Use when context is provided and needs to be analyzed for relevant information.

1. Read the provided context thoroughly.
2. Identify key themes and facts related to the question.

Check that all relevant points from the context are considered.

#### Direct Response Formation

Use when a direct answer can be formed from the identified information.

1. Synthesize the key points into a concise answer.
2. Ensure the answer directly addresses the question.

Check that the answer is clear and directly relevant.

#### Clarification Request

Use when the question is ambiguous or the context is insufficient.

1. Identify the ambiguous aspects.
2. Formulate a specific, helpful clarification request.

### Decision rules

- Use Contextual Analysis when the context is rich and detailed.
- Use Direct Response Formation when the question is straightforward.
- Use Clarification Request when the context or question is uncertain.

### Common failure modes

- Making claims unsupported by the context; ensure each claim is grounded in the provided details.
- Misinterpreting the question; analyze it carefully before answering.

### Output contract

- Answer clearly and directly.
- Reference specific details from the context.
- Ask for clarification politely when necessary.

## CommonGen — constrained sentence generation

### Task summary

Create a short sentence using specific words from a provided list.

### Strategies

#### Word Selection Strategy

Use when a list of words must be incorporated into a sentence.

1. Review the provided list.
2. Select words that can be combined into a coherent sentence.

Check that all selected words from the list are included.

#### Sentence Structure Strategy

Use when the selected words need to be arranged grammatically.

1. Determine the subject, verb, and object.
2. Arrange the words into a logical sentence structure.

Check that the sentence is grammatically correct.

### Decision rules

- First identify the appropriate words.
- Then apply the sentence structure strategy to construct the sentence.

### Common failure modes

- Omitting words from the list; compare the final sentence with the full input list.
- Producing an ungrammatical sentence; review the sentence before finalizing it.

### Output contract

- Return one short sentence.
- Incorporate the words from the provided list.
- Keep the sentence grammatical and coherent.

## GSM8K — mathematical question answering

### Task summary

Provide an answer based on a given context.

### Strategies

#### Contextual Extraction

Use when the context directly contains the information needed for the answer.

1. Identify the key elements in the context.
2. Extract the information that directly answers the question.

Check that the extracted information addresses the question without ambiguity.

#### Paraphrasing

Use when the context is lengthy or complex and a concise answer is needed.

1. Summarize the context while retaining essential details.
2. Rephrase the summary into a direct answer.

Check that the paraphrase preserves the original meaning.

#### Inference Making

Use when the context implies information that is not stated explicitly.

1. Analyze implicit meanings and assumptions.
2. Formulate an answer based on logical deductions.

Check that the inference follows logically from the context.

### Decision rules

- Use Contextual Extraction when the answer is stated directly.
- Use Paraphrasing when the context is long or complex.
- Use Inference Making when the answer must be deduced.

### Common failure modes

- Misunderstanding the context; read and interpret it carefully.
- Giving an answer unrelated to the question; keep the response focused.

### Output contract

- Answer clearly, concisely, and directly.
- Represent all relevant information accurately.
- Avoid ambiguity and logical inconsistencies.

## TweetEval — sentiment classification

### Task summary

Classify the sentiment of a text as positive, negative, or neutral.

### Strategies

#### Keyword Analysis

Use for short texts with explicit emotional language.

1. Identify keywords and phrases indicating sentiment.
2. Classify based on positive or negative indicators.

Check that the keyword set covers varied sentiment expressions.

#### Contextual Analysis

Use for longer or more complex text where context and tone matter.

1. Read the entire text.
2. Determine sentiment from the overall message rather than isolated keywords.

Check that the label matches the overall theme.

#### Machine Learning Model

Use when processing large volumes of text or when high accuracy is required.

1. Select a suitable pretrained sentiment model.
2. Run the text through the model.

Check the model's reliability on representative data.

### Decision rules

- Use Keyword Analysis for short, explicit messages.
- Use Contextual Analysis for nuanced or longer messages.
- Use a Machine Learning Model for large-scale or high-accuracy classification.

### Common failure modes

- Misclassifying ambiguous language; seek additional context or combine strategies.
- Over-relying on keywords; incorporate contextual analysis.

### Output contract

- State exactly one label: positive, negative, or neutral.
- The generated playbook also recommends a brief justification, although the benchmark metric may prefer only the label.

## XSum — abstractive summarization

### Task summary

Condense a given sentence while retaining its essential meaning.

### Strategies

#### Key Concept Extraction

Use when the input contains several ideas or details that can be reduced to a core message.

1. Identify the main subject and action.
2. Remove unnecessary adjectives, adverbs, and details.
3. Rephrase the core message concisely.

Check that the summary preserves the original meaning.

#### Paraphrasing

Use when rewording can simplify a straightforward sentence.

1. Read the sentence thoroughly.
2. Rewrite it with different wording while preserving meaning.
3. Shorten it where possible.

Check that the paraphrased version is shorter than the original.

#### Elimination of Redundancies

Use when the input contains repetitive ideas or phrases.

1. Identify redundant words and phrases.
2. Remove them without losing clarity.

Check that the complete message remains intact.

### Decision rules

- Choose the strategy based on the complexity and structure of the input sentence.

### Common failure modes

- Over-simplifying and losing critical information; retain all key points.
- Misinterpreting the original meaning; verify the core message before finalizing.

### Output contract

- Make the summary shorter than the original sentence.
- Preserve the main idea accurately.
- Use clear and concise language.
